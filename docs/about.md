# About

noodl has been a long time coming. John Craske and Maarten van Reeuwijk have discussed the idea behind it for many years, ever since John became interested in complex networks: a single framework in which the airflow through a building, the heat and contaminants it carries, the air in a street canyon and the water in a sewer or supply network are all the same mathematical object — a network whose branches carry flows and whose nodes conserve what passes through them — and in which every result can be differentiated, so that a model can be calibrated against measurements or run backwards as easily as it is run forwards.

The vision was clear long before there was time to build it. With the help of Claude, Anthropic's AI model, it has now been implemented far more efficiently than would otherwise have been possible: the design, the code, the checks against reference implementations and this documentation were developed with Claude, under the authors' direction and review.

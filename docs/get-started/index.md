# Get started

Install noodl physics, build a first model, then run or calibrate one of your own.

- [Installation](installation.md): install the package and check it works.
- [Your first model](first-model.md): build and run a small network.
- [Run a model from a file](run-from-file.md): load an existing CONTAM, SWMM, EPANET, MATPOWER, Modelica or WSIMOD file.
- [Calibrate against data](calibrate.md): fit parameters with gradients.

# Get started

Install noodl physics, build a first model, then run and calibrate a model read from a file.
Each tutorial runs as written.

1. [Installation](installation.md): install the package and the extras you need.
2. [Your first model](first-model.md): a two-node network, solved, batched and differentiated.
3. [Run a model from a file](run-from-file.md): read an EPANET network and read the results by name.
4. [Calibrate against data](calibrate.md): fit a parameter to measurements with gradients.

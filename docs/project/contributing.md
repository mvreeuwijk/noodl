# Contributing

Contributions are welcome. The full rules are in [CONTRIBUTING.md](https://github.com/mvreeuwijk/noodl/blob/main/CONTRIBUTING.md).

In short: code, tests and documentation change together, `ruff check .` runs before every commit,
and the test suite and the documentation build must pass. See [Testing](testing.md) and
[Extending noodl](extending/index.md).
